# 🚂 Rail Vision — распознавание настоящих рельсов по реальным фото

Система компьютерного зрения, которая по **реальной фотографии или видео**
определяет, есть ли в кадре **настоящие рельсы**, и показывает, где именно они
проходят.

```
реальные фото из интернета  ->  разметка  ->  обучение RailNet  ->  детекция на фото/видео
   (Open Images V7)           (semi-auto)     (CPU, PyTorch)        (маска + линии рельсов)
```

## Что внутри

| Компонент | Файл | Назначение |
|---|---|---|
| Сбор датасета | `scripts/fetch_openimages.py` | качает реальные фото ж/д и негативы из Open Images V7 (метки проверены людьми) |
| Геометрический детектор | `src/detection/geometric_rails.py` | находит колею без обучения: точка схода, ректификация «вид сверху», периодичность шпал |
| Разметка | `scripts/label_rails.py` | полуавтоматическая разметка: предложения детектора + примагничивание линий к головкам рельсов |
| Модель | `src/detection/models/railnet.py` | ResNet-18 (ImageNet) + FPN: классификация «есть рельсы» и сегментация рельсов |
| Обучение | `scripts/train_railnet.py` | мультизадачное обучение на CPU |
| Self-training | `scripts/self_train.py` | сеть сама размечает новые кадры, разметка фильтруется по уверенности |
| **Детекция** | `scripts/detect.py` | **главный скрипт: фото / папка / видео / камера** |
| Оценка | `scripts/evaluate.py` | честные метрики на hold-out + отчёт |

## Быстрый старт

```bash
pip install -r requirements.txt

# 1. Скачать реальные фотографии (≈4-5 тыс. кадров, ~1 ГБ)
python scripts/fetch_openimages.py --out data/real --pos 3200 --neg 3200

# 2. Обучить модель (CPU)
python scripts/train_railnet.py --epochs 12 --img-size 288

# 3. Найти рельсы на своём фото или видео
python scripts/detect.py --input my_photo.jpg --out result.jpg
python scripts/detect.py --input clip.mp4    --out clip_rails.mp4
python scripts/detect.py --input 0           --out cam.mp4      # веб-камера
```

## Данные

Источник — [Open Images Dataset V7](https://storage.googleapis.com/openimages/web/index.html):
настоящие фотографии с метками, **проверенными людьми**.

* **позитивы** — метки `Railway`, `Tram`, `Locomotive`, `Railroad car`,
  `High-speed rail`, `Train`;
* **негативы** — кадры, где человек подтвердил отсутствие ж/д, и «трудные»
  сцены с похожей перспективой: `Road`, `Highway`, `Street`, `Path`, `Fence`,
  `Forest`, `Sidewalk`, `River`;
* **hold-out** — кадры из сплитов validation/test (в обучении не участвуют).

Сами изображения в репозиторий не коммитятся (`data/` в `.gitignore`) —
скрипт скачивает их заново.

## Разметка рельсов

У исходных фото нет масок рельсов, поэтому они получены в цикле
«предложение → визуальная проверка → примагничивание»:

1. геометрический детектор предлагает варианты колеи;
2. предложения ранжируются по `score детектора × вероятность классификатора`;
3. человек глазами принимает или отклоняет вариант (`accept` / `reject`);
4. линии автоматически уточняются по карте гребней яркости — то есть
   ложатся ровно на головку рельса;
5. дальше сеть сама размечает новые кадры (self-training), а разметка
   фильтруется по уверенности.

Негативные кадры дают «бесплатную» разметку: корректная маска рельсов там пустая.

## 3D-модуль (стерео)

Отдельная ветка проекта — восстановление рельсов в 3D по стереопаре:
`src/camera` (калибровка, SGBM-глубина), `src/reconstruction` (облако точек,
RANSAC), `src/tracking` (фильтр Калмана), `src/visualization`.
Демо на синтетических данных: `python scripts/demo.py`.

## Технологии
